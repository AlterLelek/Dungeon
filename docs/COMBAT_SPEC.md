# Бой MM6 — замороженная спецификация

Этот документ — источник истины для расчёта урона и текста журнала боя. Формулы и
формулировки ниже менять нельзя без отдельной задачи.

## 1. Единственная формула урона

```
damage = max(0, attack - defense)
```

- `attack` — целое число атаки атакующего (`heroAtk(h)` для героя, `m.atk` плюс
  фиксированный `m.magicBonus` для монстра с магией).
- `defense` — целое число защиты цели (`target.defVal` для врага, `heroDef(h)` для героя).
- `damage` — целое неотрицательное число. Отрицательная разница означает ноль урона.

Запрещено добавлять крититы, дробные значения, проценты, шансы увертывания,
случайные надбавки к атаке и деление защиты пополам. Заклинания, яд и эффекты
предметов остаются отдельными механиками; если эффект меняет атаку, он уже
учтён в числе `attack` и виден в журнале.

## 2. Формат строки журнала

```
«<Кто> <глагол> <Чем> и получил <атака> атаки против защиты <защита>. <Цель> получил(а) <урон> урона.»
```

Глагол «получил/получила» согласуется с атакующим и с целью. Оружие даётся в
творительном падеже (`Топором`, `Мечом`, `Кулаками`). Для монстра без оружия
используется его глагол (`укусила`), для монстра с магией — `колдовал чарами`.

Формулировки «нанес урона, но защитился», «критический удар», упоминания шансов
и процентов в журнале боя недопустимы.

## 3. Атака без оружия

Кулаки — не предмет, а классовая атака. Значение берётся из `FIST_ATTACK` в
`games/mm6/data.js`, затем к нему применяются бонусы героя. Минимум — 2.

| Класс / герой | Атака кулаками |
|---|---:|
| Гном-кулига | 5 |
| Воин | 4 |
| Паладин, Ангел | 3 |
| Разбойник, Амазонка | 3 |
| Маг, Следопыт, Друид, Гном-колдун | 2 |

## 4. Проверочный бой (один в один)

| Атакующий | Оружие / действие | Атака | Защита цели | Урон |
|---|---|---:|---:|---:|
| Воин | Топор | 16 | 7 (Черепаха) | 9 |
| Черепаха | укус | 3 | 0 (Воин) | 3 |

Фрагмент журнала, который должен получиться при таких числах:

> Воин ударил Топором и получил 16 атаки против защиты 7. Черепаха получила 9 урона.
>
> Черепаха укусила и получила 3 атаки против защиты 0. Воин получил 3 урона.

Проверка: `16 - 7 = 9`, `3 - 0 = 3`. Числа в тексте совпадают с расчётом без
округлений и скрытых надбавок.

## 5. Доступность действий

- «Магия» открывает меню выбранного героя только в его ход и только если есть
  изученное заклинание с эффектом и хватает маны. Каждая строка меню показывает
  причину недоступности в `title`.
- «Бегство» доступно только в незавершённом бою в ход героя. Шанс успеха
  зафиксирован: 50%. При неудаче ход получает самый быстрый живой враг.
- Недоступное действие никогда не превращается в атаку: причина выводится в
  `title` кнопки и тостом.

## 6. Нагрузка, скорость и магия в металле

Этот раздел замораживает правила экипировки из `docs/DESIGN.md`. Разделы 1–5
остаются без изменений. Класс предмета сохраняется в данных как атрибут и
**никогда не блокирует** надевание.

### 6.1. Вес предметов

| Категория предмета | Вес |
|---|---:|
| Ткань (роба, тканевая одежда) | 1–3 |
| Кожа | 3–6 |
| Лёгкий металл (кольчуга, сталь, латные элементы) | 5–8 |
| Тяжёлая броня | 8–15 |
| Посох, палочка, книга | 1–2 |
| Меч, кинжал | 3–4 |
| Топор, молот | 5–7 |
| Копьё | 4–5 |
| Лук, арбалет | 3–6 |
| Кольца, амулеты, плащи | 0–1 |
| Расходники (зелья, травы, еда, свитки, материалы, кристаллы) | 0 |
| Знамя (только носителю) | 2–4 |

Каждый создаваемый предмет получает поле `weight`. Вес улучшений и качества
оружия/брони не меняется. Кулаки не предмет и веса не имеют.

### 6.2. Сила и грузоподъёмность

```
capacity = 10 + strength × 5
```

| Набор героя | Сила | Грузоподъёмность |
|---|---:|---:|
| Воин (`warrior`) | 8 | 50 |
| Следопыт (`archer`) | 5 | 35 |
| Маг (`mage`) | 2 | 20 |

Имена героев наследуют силу своего набора: Паладин и Гном-кулига — 8,
Разбойник и Амазонка — 5, Ангел, Друид и Гном-колдун — 2. Других источников
силы нет.

### 6.3. Что взвешивается

Взвешивается **только надетое**: оружие и броня во всех слотах манекена.
Предметы в сумке, золото и кристаллы в вес не входят. Псевдонимы слотов `body`
и `armor` указывают на один предмет и учитываются один раз.

```
wornWeight = сумма weight у уникальных надетых предметов
ratio      = wornWeight / capacity
```

### 6.4. Уровни нагрузки и скорость

| Условие | Уровень | Множитель скорости | Магия |
|---|---|---:|---|
| `ratio ≤ 0.5` | норма | ×1 | доступна |
| `0.5 < ratio ≤ 1` | заметная нагрузка | ×0.75 | доступна |
| `ratio > 1` | перегруз | ×0.5 | недоступна |

Итоговая скорость героя в очереди боя:

```
speed = round1(max(1, baseSpeed × settings.heroSpeed × loadMultiplier))
```

`baseSpeed` вычисляется как раньше из набора героя, оружия и статусов; округление
до одного знака — последним. В сводке перед боем и в строке очереди показывается
уже итоговая скорость. При перегрузе перед боем добавляется одна строка журнала:

```
⚠ <Герой> перегружен: <вес>/<ёмкость> (<процент>%). Скорость ×0.5, магия недоступна.
```

### 6.5. Провал магии в металле

Учитывается вес надетой брони категорий `heavy` и `light_metal`:

```
failChance = min(100, metalWeight × 5)   // в процентах, metalWeight — целое число
```

Проверка делается после списания маны и до любого эффекта заклинания. При
провале мана не возвращается, эффект не применяется, ход переходит дальше.
Фиксированная строка журнала:

```
«<Герой> пытался применить «<Заклинание>», но метал сковал чары: провал (<N>%). Мана потрачена.»
```

Перегруз проверяется раньше: при `ratio > 1` магия недоступна полностью и
проверка металлической брони не проводится.

### 6.6. Отображение

- В инвентаре показывается полоска нагрузки: зелёная при `ratio ≤ 0.5`,
  жёлтая при `0.5 < ratio ≤ 1`, красная при `ratio > 1`, с подписью
  `<вес>/<ёмкость> (<процент>%) · скорость ×N`.
- В описании предмета в инвентаре и лавке для выбранного героя показываются
  вес предмета и прогноз нагрузки после надевания.
- Кнопка «Надеть» активна и при перегрузе; в `title` указаны последствия
  (`скорость ×0.5, магия недоступна`). Классовых запретов и предупреждений нет.
