# Dungeon

Хаб игр: Dungeon 28, Labyrinth, SF2 Battles и «Авантюрист» (MM6).

- [Боевая спецификация MM6](docs/COMBAT_SPEC.md) — замороженная формула урона,
  формат журнала боя и проверочный бой.
- Каталог ресурсов: `assets/manifest.json` (обновление — `npm run build:manifest`).
- Локальный запуск: `./serve-dungeon.ps1`, затем `http://localhost:3000/`.
