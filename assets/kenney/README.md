#Внешние CC0-спрайты

Минимальный набор PNG из двух паков Kenney (CC0 1.0, public domain):

- **Tiny Town** — `tiles/`: здания.
- **Tiny Dungeon** — `items/`: оружие, броня, зелья, свитки, сундуки, монеты.

Земля, трава, песок, камень и цветы рисуются программно в `games/mm6/index.html`;
`games/mm6/terrain.js` содержит вспомогательные палитры и функции рельефа.
Соответствующие PNG-тайлы удалены.

Источники:

- https://kenney.nl/assets/tiny-town
- https://kenney.nl/assets/tiny-dungeon

Лицензии лежат в `licenses/`. Файлы переименованы в семантические имена;
